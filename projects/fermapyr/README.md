# FERMAPYR — iron provenance pipeline (Jupyter notebook)

Supplementary notebook for the publication *"Machine learning for iron
provenance: a geochemical and spatial approach applied to the eastern French
Pyrenees"*.

`pipeline_complet_fermapyr.ipynb` runs the complete analysis in 14 steps, from
the raw geochemical data to the provenance maps:

| Step | Content | Publication item |
|---|---|---|
| Setup | shared imports, constants and functions (run this cell first) | — |
| 1 | Wasserstein geochemical distance between production sites | — |
| 2 | ClustGeo spatially constrained clustering (alpha = 0.5, K = 12) | Figures 3 and 5 |
| 3 | Production sites table | Table 1 |
| 4 | Archaeological objects table | Table 2 |
| 5 | Production sites map | Figure S1 |
| 6 | Archaeological objects map | Figure S2 |
| 7 | Interactive biplots (exploration) | — |
| 8 | Random Forest model | — |
| 9 | SVM model | — |
| 10 | Neural network model (Keras Tuner hyperparameter search) | — |
| 11 | RF / SVM / NN comparison and consensus | Table S1 |
| 12 | Consensus provenance map | Figure S4 |
| 13 | Provenance maps per method, 60 % confidence threshold | Figures S5–S7 |
| 14 | Provenance maps per method, 80 % confidence threshold | — |

## Installation

Python 3.12 is required. From a terminal, in this folder:

```bash
python3.12 -m venv venv
./venv/bin/python3 -m pip install -r requirements.txt
```

(On Windows, use `venv\Scripts\python.exe` instead of `./venv/bin/python3`.)

## Running the notebook

**The notebook must be opened from this folder**: the input files are read from
the current working directory, and all outputs are written to it as well. The
first code cell (Setup) checks that the 8 input files are present and stops
with an explicit message otherwise.

*PyCharm*: open this folder as a project (`File > Open…`), select the `venv`
interpreter (`Settings > Project > Python Interpreter`), open the notebook,
run the Setup cell, then the other cells in order (or `Run All`).

*JupyterLab*:

```bash
./venv/bin/python3 -m jupyter lab
```

Steps must be run in order (each step reads the files written by the previous
ones). Run the Setup cell first.

## Outputs

Everything is written to this folder, for example:

- `matrice_brute.csv`, `coordonnees_sites.csv` (step 1);
- `clusters_alpha0.5_K12.csv`, `nombre_individus_par_cluster_alpha0.5_K12.csv`,
  `dendrogramme_clustgeo.png`, `qualite_clustgeo.png` (step 2);
- `tableau_sites_periode_scories_alpha0.5_K12.xlsx` (Table 1),
  `tableau_objets_sites_periodes_EN.xlsx` (Table 2);
- `RF_*`, `SVM_*`, `NN_*` Excel files: cross-validation results, mean class

- `comparison_predictions_RF_SVM_NN_Group_alpha0.5_K12_EN.xlsx` (Table S1);
- interactive maps `carte_*.html` (Plotly; they are written to disk but not
  opened automatically — open them in a web browser).

## Notes

- **Run time**: about 20–30 minutes for the whole notebook, dominated by the
  neural-network hyperparameter search (step 10, about 15 minutes). Steps 1–6
  take seconds to a few minutes.
- **Reproducibility**: steps 1–3 (distances and ClustGeo clustering) are
  deterministic and give the same clusters at each run. The RF, SVM and neural
  network results (steps 8–10) depend on random train/test splits and on the
  hyperparameter search, so probabilities and the objects close to a decision
  boundary can change slightly from one run to another. The values reported
  in the publication are those of Table S1.
- **Interactive prompts**: the interactive cluster-merging dialog of the
  original scripts is replaced by the grouping used in the publication
  (clusters 1 and 7 merged into group `G1_7`, named "Rancié"; cluster 11 is
  named "Canigou").
- **Matplotlib windows**: some steps open matplotlib figures with `plt.show()`;
  depending on the backend they may need to be closed before the run continues.
